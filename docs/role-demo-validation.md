## Interprétation

Le badge et le rang public sont une couche d’identité éditoriale gérée par Premium Forum Core. Les permissions effectives dépendent du rôle WordPress et du rôle bbPress. `atelier_test` utilise le rôle WordPress `Membre SVIP` et le rôle bbPress `Participant`. `atelier_moderateur` utilise le rôle WordPress `Abonné` et le rôle bbPress `Modérateur`, avec le rang public `Modérateur`.

Le compte SVIP bénéficie d’une identité communautaire premium, de l’affichage du badge, du suivi des sujets, des notifications internes et des indicateurs de contribution comme les votes reçus selon les fonctionnalités activées. Le rôle SVIP ne donne pas automatiquement les droits de modération.

Le compte Modérateur dispose du rôle bbPress `Modérateur`, qui sert aux actions de gouvernance du forum selon les capacités bbPress configurées : gérer les discussions et réponses, fermer ou déplacer un sujet, et intervenir sur les contenus selon les règles du site. Le badge `Modérateur` rend cette fonction identifiable ; il ne doit pas être confondu avec un simple libellé décoratif.
